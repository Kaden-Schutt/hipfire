PROMOTE an autoresearch WIN into an arch-specific kernel FORK (anti-clobber: form-fitting per arch, never
overwrite the shared <k>.hip that other arches JIT-compile). Inputs: KERNEL=<name>, ARCH=<gfx1100|gfx1201|...>,
WINNING_VARIANT=<path to the winning .hip source>, BASELINE_REF.

WHY FORK (not overwrite shared): the shared kernels/src/<k>.hip is include_str!'d and JIT-compiled per arch.
A gfx1100-tuned change (e.g. SLC/streaming loads that fix RDNA3's DRAM-thrash) is WRONG for gfx1201 (already
L2-resident — streaming would hurt it). Overwriting <k>.hip reshapes EVERY arch. So arch-specific wins fork.

STEP 0 — UNIVERSAL vs ARCH-SPECIFIC: if the win's mechanism is arch-neutral AND it was cross-arch re-verified
non-negative on the other active arches, it MAY replace the shared <k>.hip (the attention register-ring was
this: universal +on both). Otherwise (arch-specific lever, or not re-verified elsewhere) → FORK. Default to FORK.

STEP 1 — write the fork source:  cp WINNING_VARIANT  kernels/src/<KERNEL>.<ARCH>.hip
  (keep the SAME __global__ symbol name + signature as the shared kernel; only the body differs.)

STEP 2 — register the include_str! const in crates/rdna-compute/src/kernels.rs, next to the existing
  <K>_<ARCH>_SRC consts (match the surrounding naming), e.g.:
     pub const <K_UPPER>_<ARCH_UPPER>_SRC: &str = include_str!("../../../kernels/src/<KERNEL>.<ARCH>.hip");

STEP 3 — wire the dispatch. Find the <k>_for_arch(caps) selector (or the site that returns this kernel's
  (source, module_name)). Add/modify the arm for THIS arch so it returns (<K>_<ARCH>_SRC, "<kernel>_<arch>").
  CRITICAL: the module_name MUST be DISTINCT per arch-variant (reference_kernel_module_cache_collision — the
  JIT cache keys on module name; a fork under the shared name is dead code). Leave the base arm + all other
  arches UNTOUCHED. If no _for_arch selector exists yet for this kernel, create one following the pattern of
  the existing MQ4-Lloyd *_for_arch selectors (match arch: this arch -> fork; _ -> shared base).

STEP 4 — VERIFY the workspace still builds (the CI-required check, feature-unification on so deltanet compiles):
     cargo build --release --workspace --all-targets --locked
  If it fails, fix the registration (missing const, wrong path, duplicate module name) before proceeding.

STEP 5 — commit to the card branch: git add kernels/src/<KERNEL>.<ARCH>.hip crates/rdna-compute/src/kernels.rs
  (+ the dispatch file if separate); commit "FORK <KERNEL>.<ARCH> <lever> d=<delta>%".
