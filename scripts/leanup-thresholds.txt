# Format:  <metric> <op> <value>
#   ==  must equal exactly

# one requires a sentence in the commit message saying what was traded for it --
# otherwise the ratchet stops meaning anything, which is precisely the failure
# this file exists to end. Before 2026-08-16 the script emitted 22 metrics and
# contained exactly one `exit 1`, guarding `cd`.
