## Purpose

Policy boundary between HIP source and LLVM/AMDGPU (vendored from upstream `redline` @ `f4a0994`, see [`VENDOR.md`](VENDOR.md)). Injects reviewed source-level lowering rules, invokes `hipcc`, inspects the emitted code object, and records reproducible build evidence. Owns `Atomics`/`Oracle`/`Partition`/`Campaign`/`Recipes` modules; the `//!` docs in [`src/lib.rs`](src/lib.rs) are authoritative.

## Gotchas

- Vendored crate — do not edit lowering rules without recording build evidence; `arch.rs`/`CodeObjectIdentity` tracks reproducibility.
- LLM/hipcc invocation is toolchain-sensitive; `toolchain.rs` / `campaign.rs` encapsulate the exact `hipcc` flags and ISA versioning.
