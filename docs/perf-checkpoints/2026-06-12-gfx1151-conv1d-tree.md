# gfx1151 DeltaNet Tree Conv

Date: 2026-06-12
Host GPU: gfx1151 (Strix Halo)
Branch: `chaingun`

## Question

Qwen3.5 / Qwen3.6 DFlash tree verification still routed
`conv1d_silu_split_tree_f32_n` through the generic F32 tree kernel. Unlike
routed-session conv, tree conv does not update conv state. Each token reads
`parent_indices[]`, input, weights, and the initial state, then writes Q/K/V.
That makes `(token, channel)` cells independent and safe to parallelize on
gfx1151.

## Commands

```bash
HIPFIRE_CONV1D_TREE_GFX1151=0 \
  cargo run --release --features deltanet -p rdna-compute \
  --example bench_conv1d_tree_gfx1151

cargo run --release --features deltanet -p rdna-compute \
  --example bench_conv1d_tree_gfx1151

cargo run --release --features deltanet -p rdna-compute \
  --example test_conv1d_tree
```

Log:

- `/tmp/gfx1151-conv1d-tree-bench-20260612-095456.log`

## Correctness

`test_conv1d_tree` passed on gfx1151:

- spine Q/K/V: byte-exact against linear conv
- decode Q/K/V: byte-exact
- sibling topology: max error <= `5.96e-8`

## Results

Shape: `k_dim=128`, `v_dim=256`, 1000 trials.

| n_tokens | generic us | gfx1151 us | speedup |
|---:|---:|---:|---:|
| 4 | 3.112 | 2.261 | 1.38x |
| 8 | 3.716 | 2.455 | 1.51x |
| 16 | 5.573 | 2.424 | 2.30x |
| 32 | 8.887 | 2.581 | 3.44x |
| 64 | 15.760 | 2.729 | 5.77x |

## Decision

Default gfx1151 to the token-parallel tree conv kernel. Keep
`HIPFIRE_CONV1D_TREE_GFX1151=0` as an A/B escape hatch. Routed-session conv
remains generic because it mutates per-session state sequentially.
