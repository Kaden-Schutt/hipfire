# Spec records

**Lifecycle.** Records under this directory are preserved specification
intent and contract history. They are not the live product surface.

**Allowed claim use.** Cite a record only as intended contract,
proposed interface, or historical spec context. Map any stronger claim
to the vocabulary in the [documentation authority index](../INDEX.md):
`shipped/ref-pinned`, `branch-implemented`, `measured`, or `planned`.
Unknown or blocked stays fail-closed. Recent modification time, frozen
status, task completion, and checked boxes do **not** establish
implementation or admission.

**Current-owner route.** For present-tense facts, follow the domain
owner listed in [../INDEX.md](../INDEX.md). Do not treat any spec file
here as current runtime truth.

**Preservation.** Preserve every existing record body byte-for-byte; never rewrite or delete historical prose.
