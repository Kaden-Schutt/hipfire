# hipfire quant-type register — the committed allocation of `.hfq` qt numbers.
#
# This file is the SOURCE OF TRUTH for which quant-type numbers exist and what
# each one's load disposition is. `scripts/check-quant-registry.py` asserts the
# tree against it, in both directions:
#
#   qt_unlisted              a QuantType variant that is not in this table
#   qt_stale                 a row here that names no QuantType variant
#   qt_unparseable           a variant `QuantType::from_u8` refuses
#   qt_disposition_mismatch  a row whose disposition contradicts RAW_CODECS
#
# Why a table and not a count. A ceiling like `qt_unregistered <= 10` cannot see
# substitution: drop one justified entry, add an unjustified one, the count is
# unchanged and the gate stays green. That is the shape of f00fa8058, where the
# qt=43 work deleted six match arms while adding its own and the build stayed
# green. Identity is checked here, not cardinality.
#
# Claiming a number means editing THIS file, which makes two branches claiming
# the same number a merge conflict in forty lines of text rather than a silent
# overwrite discovered after release.
#
# First adjudication, 2026-08-18: PR #597 (BQ1G128) and PR #599 (MQ1G1024GL)
# both claimed qt=41. Ruled for #597 — MQ1G1024GL was never wired or tested,
# and BQ1G128 is substantially the same format. qt=41 is reserved for BQ1G128
# below; #599 must pick another number when it returns from draft.
#
# Dispositions
#   passthrough   uploaded verbatim; MUST have a RAW_CODECS row in
#                 crates/hipfire-runtime/src/weight_backend.rs
#   host-decode   widened on the host in dequant_weight_raw; MUST NOT have a row
#   arch-loaded   an arch crate owns the upload path; MUST NOT have a row
#   non-weight    not a quantized weight tensor at all
#   reserved      claimed for work not yet landed; the ONLY disposition exempt
#                 from the STALE check, so a number can be held before its
#                 QuantType variant exists. Convert the row when the code lands.
#
# Reserved / never reuse: 23, 25, 26, 27 (deliberately unassigned).
