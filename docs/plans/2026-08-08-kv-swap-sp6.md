# SP6 KV Swap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An idle session's KV and DeltaNet state survive losing its slot, so the daemon can hold 30+ sessions against 4 resident slots.

**Architecture:** A session's GPU state is captured into a stamped, checksummed `SlotSnapshot` held in host RAM (up to a budget) or spilled to a scratch file. Eviction is LRU over idle sessions only; write-out is async, read-in blocking. Every failure marks the session `Cold` and the next turn re-prefills from its tokens.

**Tech Stack:** Rust, `hipfire-runtime`, `rdna_compute::{Gpu, slot_pool::SlotPool}`, `hipfire_arch_qwen35::qwen35::DeltaNetState`, std threads for write-back.

## Global Constraints

- **The tokens are authoritative; KV is only a cache.** Every failure path degrades to re-prefill, never to wrong output. No `unwrap()` on any IO or checksum path.
- **The swap unit is `{KV slab, DeltaNet state, seq_len, tokens}` — all four or none.** DeltaNet state lives outside the KV arena; a KV-only implementation passes a short smoke test and fails subtly on long conversations.
- **Validate in host memory, then commit to VRAM in a single pass.** Stamp and length before reading payload; checksum before any H2D copy. A live slot is never left half-written.
- **Residency is a property of the session, not the slot.** A restored session may land in a different slot; nothing may assume slot affinity.
- **Transfer only the live prefix:** `seq_len × per_pos_bytes` per layer, not `cap`.
- Host tier budget default **16 GiB**, overridable.
- Spill files are **scratch**: deleted on session close, directory cleared at startup. The stamp is written anyway so persistence is a later policy change.
- Formatting: `BASE_REF=origin/beta ./scripts/fmt-changed.sh`. GPU harnesses under `./scripts/run-bounded.sh`.

### Task 1: `SlotSnapshot` — capture and restore

**Files:**
- Create: `crates/hipfire-runtime/src/swap/snapshot.rs`, `crates/hipfire-runtime/src/swap/mod.rs`
- Modify: `crates/hipfire-runtime/src/lib.rs` (add `pub mod swap;`)

**Interfaces:**
- Consumes: `rdna_compute::{Gpu, GpuTensor, slot_pool::SlotPool}`, `hipfire_arch_qwen35::qwen35::DeltaNetState`.
- Produces:
  - `pub struct SnapshotStamp { pub model_hash: u64, pub kv_dtype_tag: u32, pub per_pos_bytes: u32, pub n_fa_layers: u32, pub dn_layout_version: u32, pub cap: u32 }`
  - `pub struct SlotSnapshot { pub stamp: SnapshotStamp, pub seq_len: usize, pub tokens: Vec<u32>, pub payload: Vec<u8>, pub checksum: u64 }`
  - `pub enum SwapError { Stamp(String), Corrupt(String), Io(String), Gpu(String) }`
  - `pub fn capture_slot(gpu: &mut Gpu, pool: &SlotPool, slot: SlotId, k_arenas: &[GpuTensor], v_arenas: &[GpuTensor], dn: &DeltaNetState, tokens: &[u32], stamp: SnapshotStamp) -> Result<SlotSnapshot, SwapError>`
  - `pub fn restore_slot(gpu: &mut Gpu, pool: &mut SlotPool, slot: SlotId, k_arenas: &[GpuTensor], v_arenas: &[GpuTensor], dn: &DeltaNetState, snap: &SlotSnapshot, expect: SnapshotStamp) -> Result<(), SwapError>`

**Payload layout (fixed, documented in the file):** for each FA layer `l` in model order, `seq_len × per_pos_bytes` bytes of K from `k_arenas[l]` at `desc.k_base`, then the same span of V from `v_arenas[l]` at `desc.v_base`; then the DeltaNet state bytes in `DeltaNetState`'s own buffer order.

- [ ] **Step 3: Implement `snapshot.rs`**

Write the types with: a `MAGIC: u64 = 0x484950465F535731` (`"HIPF_SW1"`) and `VERSION: u32 = 1` in the serialised header; `checksum_of` as FNV-1a over the payload (the same 64-bit FNV already used in `replay.rs::capture_summary`, for consistency); `validate(&self, expect: SnapshotStamp)` checking stamp equality first, then `payload.len() == expected_len()`, then checksum; `expected_len()` = `n_fa_layers × 2 × seq_len × per_pos_bytes + dn_bytes`; `to_bytes`/`from_bytes` with the header written little-endian and `from_bytes` rejecting wrong magic, wrong version, or a short buffer *before* indexing.

Create `crates/hipfire-runtime/src/swap/mod.rs` with `pub mod snapshot; pub mod store;` and the `SwapError` enum; add `pub mod swap;` to `lib.rs`.

### Task 2: The round-trip gate — bitwise, on real GPU state

**Files:**
- Create: `crates/hipfire-runtime/examples/test_swap_roundtrip.rs`

**Interfaces:**
- Consumes: Task 1's `capture_slot`, `restore_slot`, `SlotSnapshot`, `SnapshotStamp`, `SwapError`.

**Why:** Task 1's unit tests prove the *container* is sound. They cannot prove the GPU copies address the right bytes. This gate does, and it is the one that catches a forgotten DeltaNet state.

- [ ] **Step 1: Write the gate**

Copy the model/arena/DN setup preamble from `crates/hipfire-runtime/examples/demo_multislot_generate.rs`. Then:

```rust
// 1. Prefill a slot with a real prompt so KV and DN state are non-trivial.
// 2. Capture. 3. Scribble over the slot's KV and DN state on device.
// 4. Restore. 5. Download both and compare against a pre-capture download.
//
// Step 3 is what makes this a real test: without it, a restore that copies
// nothing would still "pass".

let before_kv = download_slot_kv(&mut gpu, &pool, slot, &k_arenas, &v_arenas, seq_len);
let before_dn = download_dn(&mut gpu, &dn_states[slot.0]);
let snap = capture_slot(&mut gpu, &pool, slot, &k_arenas, &v_arenas, &dn_states[slot.0], &tokens, stamp)?;

scribble_slot(&mut gpu, &pool, slot, &k_arenas, &v_arenas, &dn_states[slot.0]);
restore_slot(&mut gpu, &mut pool, slot, &k_arenas, &v_arenas, &dn_states[slot.0], &snap, stamp)?;

let after_kv = download_slot_kv(&mut gpu, &pool, slot, &k_arenas, &v_arenas, seq_len);
let after_dn = download_dn(&mut gpu, &dn_states[slot.0]);
assert_eq!(before_kv, after_kv, "KV not restored bitwise");
assert_eq!(before_dn, after_dn, "DeltaNet state not restored bitwise");
println!("KV {} B and DN {} B restored bitwise", after_kv.len(), after_dn.len());

// Disk tier: same via to_bytes/from_bytes through a temp file.
// Negative controls, each must be REFUSED:
let mut corrupt = snap.clone();
corrupt.payload[0] ^= 0xFF;
assert!(matches!(restore_slot(.., &corrupt, stamp), Err(SwapError::Corrupt(_))));
let mut wrong = stamp; wrong.model_hash ^= 1;
assert!(matches!(restore_slot(.., &snap, wrong), Err(SwapError::Stamp(_))));
println!("negative controls fired");
println!("ALL CHECKS PASS");
```

```rust
mod tests {
    use super::*;

    fn tmpdir(name: &str) -> std::path::PathBuf {
        let d = std::env::temp_dir().join(format!("hipfire-swap-test-{name}"));
        let _ = std::fs::remove_dir_all(&d);
        d

    #[test]
    fn a_snapshot_under_budget_stays_in_host_memory() {
        let mut s = SwapStore::new(tmpdir("host"), 1 << 20).unwrap();
        s.put(1, small_snap()).unwrap();
        assert_eq!(s.tier_of(1), Some("host"));
        assert!(s.host_used() > 0);
    }

    #[test]
    fn exceeding_the_budget_spills_to_disk() {
        let mut s = SwapStore::new(tmpdir("disk"), 64).unwrap();
        s.put(1, small_snap()).unwrap();
        assert_eq!(s.tier_of(1), Some("disk"));
        assert_eq!(s.host_used(), 0, "a spilled snapshot holds no host budget");
    }

    #[test]
    fn take_returns_the_same_bytes_from_either_tier() {
        for budget in [1u64 << 20, 64] {
            let mut s = SwapStore::new(tmpdir("rt"), budget).unwrap();
            let original = small_snap();
            s.put(1, original.clone()).unwrap();
            let back = s.take(1).unwrap();
            assert_eq!(back.payload, original.payload);
            assert_eq!(back.tokens, original.tokens);
        }
    }

    #[test]
    fn take_frees_the_budget_and_the_key() {
        let mut s = SwapStore::new(tmpdir("free"), 1 << 20).unwrap();
        s.put(1, small_snap()).unwrap();
        let _ = s.take(1).unwrap();
        assert_eq!(s.host_used(), 0);
        assert!(s.take(1).is_err(), "a taken key must not resolve twice");
    }

    #[test]
    fn a_truncated_spill_file_is_an_error_not_a_panic() {
        let dir = tmpdir("trunc");
        let mut s = SwapStore::new(dir.clone(), 64).unwrap();
        s.put(1, small_snap()).unwrap();
        let f = std::fs::read_dir(&dir).unwrap().next().unwrap().unwrap().path();
        std::fs::write(&f, b"short").unwrap();
        assert!(s.take(1).is_err());
    }

    #[test]
    fn new_clears_a_stale_directory() {
        let dir = tmpdir("stale");
        std::fs::create_dir_all(&dir).unwrap();
        std::fs::write(dir.join("leftover.bin"), b"junk").unwrap();
        let _ = SwapStore::new(dir.clone(), 64).unwrap();
        assert_eq!(std::fs::read_dir(&dir).unwrap().count(), 0);

}
```

### Task 5: The swap-equivalence gate

```rust
// CONTROL: 4 sessions, 4 slots — nothing is ever evicted.
// CANDIDATE: 6 sessions, 4 slots — sessions 5 and 6 force evictions, and
//            every evicted session is later restored and continued.

assert_eq!(control_tokens, candidate_tokens, "swap changed model output");
```
