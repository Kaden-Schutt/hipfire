# Glossary — hipfire named subsystems

> **Attribution.** Several subsystems below originate outside this project or with
> contributors rather than the maintainer. This glossary does not re-state
> origination claims for any subsystem. The authoritative records are
> [`PRIOR-ART.md`](../PRIOR-ART.md) (dated, commit-hash provenance; note that
> one origination claim for **DFlash** was formally withdrawn there in favour of
> Chen, Liang & Liu, arXiv:2602.06036), [`NOTICE`](../NOTICE) (license-grade
> attribution requirements), [`CREDITS.md`](../CREDITS.md) (contributor
> inventory), and the per-file `SPDX-License-Identifier` / `SPDX-FileCopyrightText`
> headers. Consult those files for who originated what; do not infer origination
> from presence in this table.

All `Where it lives` paths are repository-relative and verified to exist on
`arch/saddle` at the time of writing. Counts in the task description (e.g.
`279 doc mentions`) are historical doc-search tallies, not a normative signal.

| Name | Definition | Where it lives | Status |
|---|---|---|---|
| **DFlash** | Block-diffusion speculative decoder that drafts an entire block in one forward pass conditioned on projected context features from the target model. A 5-layer Qwen3 decoder with non-causal bidirectional attention within the block; the output is a per-position hidden state mapped through the target's `lm_head`. The *method* is prior art (Chen et al., arXiv:2602.06036, 2026-02-05); what ships here is the RDNA lowering and the `attention_dflash` kernel. | `crates/hipfire-runtime/src/dflash.rs` (core) and `kernels/src/attention_dflash.hip` (tiled online-softmax kernel, co-authored; see `PRIOR-ART.md` §8) | `production` |
| **DSpark** | EAGLE-3-style draft-sidecar speculative path (`<stem>-dspark.<ext>` next to the trunk). Arch-agnostic core (`DsparkBody` trait, `main_proj` ingest, Markov and confidence heads, window orchestration) with per-arch bodies for dense Llama/plain-Qwen3, Qwen3.5/3.6 (DeltaNet hybrid) and DeepSeek-V4. Preferred over DFlash/MTP/n-gram at load when the sidecar is present. | `crates/hipfire-runtime/src/dspark_core.rs` (generic core); per-arch bodies `crates/hipfire-arch-llama/src/dspark_body.rs`, `crates/hipfire-arch-deepseek4/src/dspark_speculator.rs` | `production` |
| **Redline** | Bare-`libdrm` / direct-KMD GPU dispatch that bypasses the HIP runtime. Parses `.hsaco` ELFs for kernel descriptors, creates compute queues via `amdgpu_cs_ctx_create` ioctls and submits PM4 packets (`WRITE_DATA`, `DISPATCH_DIRECT`, …) without `hipModuleLoad` in the loop. | `crates/redline/src/lib.rs` (crate `redline`; siblings `crates/redline-dispatch/`, `crates/redline-rocr/`) | `research` |
| **DDTree** | Tree-structured speculative verification built from DFlash per-position top-K marginals. Pure-Rust port of Ringel & Romano Algorithm 1: best-first heap, ancestor-only visibility matrix, `follow_verified_tree` greedy walk to select the longest accepted path, with tree-attention bias overlay onto `asym{3,4,2}` flash paths. | `crates/hipfire-runtime/src/ddtree.rs` (construction + walk); verify stage `crates/hipfire-runtime/src/dflash_generic.rs` / `spec.rs` | `research` |
| **PFlash** | Top-of-prefill compression stage that scores source prompt blocks with a small drafter, keeps high-scoring spans plus mandatory anchors (sink, recent window, chat boundaries) and hands the compressed token stream to the target's existing prefill. Decode (DFlash/DDTree/AR) is unchanged. | `crates/hipfire-pflash/src/pflash.rs` (evacuated from the arch crate by leanup B3) and `kernels/src/pflash/score_fwht{2,3,4}_kv.hip` | `legacy` |
| **CASK** | Core-aware selective KV compression (arXiv:2604.10900) that sits atop TriAttention. Splits the KV budget `B` into a protected core (top-`α·B` tokens kept intact) and mergeable scratch (next `m·(1−α)·B` tokens folded via soft-max-weighted averaging over GQA-aggregated `z`-scores into `(1−α)·B` slots). | `crates/hipfire-runtime/src/cask.rs` (CPU soft-max merge v1, Q8-only); GPU merge kernels `crates/rdna-compute/src/kernels.rs` (`cask_*`) | `research` |
| **Atlas** | Kernel Atlas — typed measurement schema and JSONL writer for the bench corpus. Bench binaries emit `AtlasRow` per phase (`prefill`, `decode_ar`, `decode_dflash`) via `--emit-atlas`; `scripts/kernel_atlas.py` does ranking/iteration, `docs/methodology/kernel-atlas*.md` defines the three-layer split (collection / analysis / advisor). | `crates/hipfire-atlas/src/lib.rs` (schema, `AtlasRow`, `parse`/`render`/`suggest`/`task`) and `docs/methodology/kernel-atlas.md` | `production` |
| **Reap** | Model-agnostic selective expert pruning and re-quant overlay for MoE models (SP2+). Gathers per-expert importance, produces an `ExpertPlan` that prunes or re-quantizes cold experts and is applied as an overlay at load. | `crates/hipfire-reap/src/lib.rs` (modules `gather`, `plan`, `hook`, `load`, `source`); spec `docs/superpowers/specs/2026-06-11-generic-moe-reap-design.md` | `research` |
| **MagnumQuant** | FWHT-rotated weight quantization family (MQ4/MQ8/MQ3/MQ6/MQ2 + Lloyd variants, G256/G128). Applies a Fast Walsh-Hadamard rotation per group offline, then asymmetric (or Lloyd-Max codebook) quantization; activation rotation is fused into `RMSNorm` at GEMV/GEMM time so cost amortizes against existing work. | `kernels/src/fused_rmsnorm_mq_rotate.hip` (fused rotation kernel) and `crates/rdna-compute/src/gemv.rs` (MagnumQuant GEMV family); format `docs/QUANTIZATION.md` | `production` |
| **Radiowave** | Policy boundary between HIP source and LLVM/AMDGPU. Injects reviewed source-level lowering rules, invokes `hipcc`, inspects the emitted code object and records enough evidence to reproduce the build. Vendored from the upstream `redline` repository (`crates/radiowave/VENDOR.md`). | `crates/radiowave/src/lib.rs` (vendored; upstream `https://github.com/Kaden-Schutt/redline` @ `f4a0994`) | `production` |
| **TriAttention** | KV-cache eviction scorer that predicts attention without recomputing it. Exploits pre-RoPE Q/K concentration (`Mean Resultant Length R≈1`) to model the RoPE logit at distance `Δ` as a trigonometric series `Σ ‖E[q_f]‖·‖k_f‖·cos(ω_f·Δ+φ_f)` and scores each cached key by its predicted contribution. | `crates/hipfire-runtime/src/triattn.rs` (scoring + `EvictionCtx`); kernels `kernels/src/pflash/score_fwht*.hip` share the scoring substrate | `research` |
| **Glimmer** | Dense text architecture crate for Muse Glimmer — 3:1 sliding/NoPE-full attention, gated attention, sandwich RMSNorm with split eps, scale-less QK-norm, SiLU SwiGLU, untied `lm_head` with output multiplier and logit softcap. ~9,985 lines, cited as the existence proof that ~10k/arch is achievable. | `crates/hipfire-arch-muse-glimmer/src/glimmer.rs` (crate `hipfire-arch-muse-glimmer`) | `production` |
| **FireMap** | HIP VMM-backed KV cache (PR #549 `feat/firemap-vmm-kv`). Reserves a stable virtual address range for KV via the HIP VMM API (`hipMem*` / `VmmArena`) and grows physical backing page-aligned, keeping graph/retained base pointers stable while paging in chunks. | `crates/hip-bridge/src/vmm.rs` (`VmmArena`); design `docs/plans/2026-07-28-pr549-vmm-all-kv-adaptive-design.md` | `research` |
| **saddle** | The target substrate proposed in the lean-up programme: the interface between model and silicon that owns target-agnostic composition (weight manifests, KV, sampling, grammar, spec-decode orchestration) so per-arch crates become thin trait implementations. Named for the interface that makes raw power rideable (and the optimisation-theory second reading). | `docs/governance/2026-08-15-saddle-design-grounding.md` (design grounding + layering diagram) and the `saddle-*` workspace crates | `research` |
| **saddle-core** | Crate implementing the saddle substrate's target-agnostic concerns. Declares four modules — `grammar`, `kv`, `caps`, `sampling` — and sits **below** `hipfire-runtime` and all `hipfire-arch-*` crates; may depend only on `rdna-compute`, `hip-bridge`, `serde`, `std` (layering contract in `Cargo.toml` + `lib.rs`). | `crates/saddle-core/src/lib.rs` (and `crates/saddle-core/Cargo.toml`); modules `crates/saddle-core/src/{grammar,kv,caps,sampling}.rs` | `research` |
